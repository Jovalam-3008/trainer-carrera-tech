# Trainer de Carrera Tech

Centro editable de aprendizaje, proyectos y productividad para la transición de Data Science a ML/AI Engineering.

## Qué incluye

- Mapa modular de 15 módulos (M0–M14) con cuatro estados por competencia y evidencia obligatoria para marcar **Dominado**.
- Calendario semanal de bloques, con categorías y repetición semanal, junto al registro diario de tareas y energía.
- Roadmap, proyectos, lecturas, empleabilidad y revisión semanal editables.

La versión de GitHub Pages publica los archivos estáticos de `public/`. Los cambios en `main` activan el despliegue automático. La aplicación original también puede ejecutarse con Vinext.

## Datos personales

El progreso se guarda solo en el almacenamiento local del navegador. GitHub Pages y `chatgpt.site` tienen dominios distintos: **no sincronizan sus datos automáticamente**. Usa **Exportar** en una versión e **Importar** en la otra para trasladar el progreso. Conserva una copia del JSON exportado antes de borrar datos del navegador.

## Desarrollo local

Con Node.js 22.13 o superior y dependencias instaladas, ejecuta el script de desarrollo del proyecto. También puedes servir `public/` como sitio estático y abrir `trainer-carrera-tech-v2-2026.html`.
